# CubiCasa5K real floorplan samples

These five files are selected from the original [CubiCasa5K release](https://zenodo.org/records/2613548). The source repository is [CubiCasa/CubiCasa5k](https://github.com/CubiCasa/CubiCasa5k); the dataset and images are licensed [CC BY-NC 4.0](https://github.com/CubiCasa/CubiCasa5k/blob/master/LICENSE). Attribution: CubiCasa and Kalervo et al., *CubiCasa5K: A Dataset and an Improved Multi-Task Model for Floorplan Image Analysis* (2019). Use is limited by the original license.

`F1_scaled.png` is the actual drawing input. `model.svg` is human reference annotation, used only for independent scoring or the explicitly annotation-assisted vector control. It is never labelled as a raster model prediction.
